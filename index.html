Sobre Mim

Sou um Especialista em Dados com foco em arquitetura em nuvem e engenharia de dados. Minha paixão é construir ecossistemas de dados que sejam escaláveis, resilientes e orientados a valor para o negócio.

No dia a dia, minha linguagem principal é o Python. Utilizo bibliotecas como Pandas e PySpark para processamento em larga escala, aliando-as a ferramentas Cloud (AWS, GCP) para construir Data Lakes e Data Warehouses modernos.

Tenho facilidade para resolver problemas complexos e busco sempre as melhores práticas de desenvolvimento, como conteinerização com Docker, orquestração e CI/CD para garantir pipelines confiáveis.
